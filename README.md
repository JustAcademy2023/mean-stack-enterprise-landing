# MEAN Stack Enterprise Landing Page

An interactive, responsive landing page about **Building Enterprise Applications Using MEAN Stack**. Tap each layer of the stack (Angular, Express.js, Node.js, MongoDB), then fire a request through all four and watch it travel.

The colour palette comes from the logos of the technologies themselves: Angular red, MongoDB green, Node.js green and Express grey on a deep MongoDB forest background.

## Features

- Interactive 3D stack with a request animation
- Responsive layout for mobile, tablet and desktop
- Sticky header, modern cards and a full footer
- Clickable links to guides and courses
- Keyboard focus styles and reduced motion support
- Pure HTML, CSS and JavaScript, no build step

## Run locally

Open `index.html` in any browser.

## Deploy with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings**, then **Pages**.
3. Under **Source**, choose the `main` branch and the `/ (root)` folder.
4. Save, and your page goes live at `https://<your-username>.github.io/<repo-name>/`.

## Customise

Change colours in the `:root` block at the top of the `<style>` tag. Edit links and text directly in `index.html`.
